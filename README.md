## 🛠️ Tecnologias Utilizadas

* **HTML5 Semântico:** Estrutura acessível com metatags otimizadas para SEO e redes sociais (Open Graph).
* **TailwindCSS (CDN):** Estilização ágil com design system customizado.
* **CSS3 Vanilla (`css/style.css`):** Animações personalizadas, efeitos de blur, glows e customizações finas.
* **JavaScript Puro (`js/main.js`):** Interatividade do menu mobile, filtros do portfólio, modal de projetos, abas do console e formulário.
* **Google Fonts & Material Symbols:** Tipografia moderna (*Plus Jakarta Sans*, *Inter*, *JetBrains Mono*) e ícones vetoriais.

## ⚙️ Como Executar Localmente

Você não precisa de dependências pesadas ou processos de compilação. Basta servir os arquivos estáticos através de qualquer servidor HTTP local:

### Usando Python:
```bash
# Na raiz do projeto, execute:
python3 -m http.server 3000
```
Acesse no navegador: `http://localhost:3000`

### Usando Node.js / npx:
```bash
npx serve .
```

### Usando a extensão Live Server (VS Code):
Basta clicar com o botão direito no arquivo `index.html` e selecionar **"Open with Live Server"**.

## 🖼️ Como Alterar a Foto de Perfil

1. Salve sua foto com o nome: **`foto-perfil.jpg`**
2. Cole o arquivo na pasta:
   ```text
   assets/images/foto-perfil.jpg
   ```
3. O site atualizará a foto automaticamente na seção **Sobre Mim** com a moldura e efeitos visuais configurados.
